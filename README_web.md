# 价格计算器网页版

这是一个响应式网页版价格计算器，可以在任何浏览器中使用，包括移动设备。

## 功能特点

- 完全保留了原Python桌面应用的所有计算功能
- 响应式设计，自动适应不同屏幕大小（包括iPhone等移动设备）
- 无需安装任何软件，直接在浏览器中打开使用
- 自动计算功能，输入数据后即时显示结果

## 使用方法

1. 直接在浏览器中打开`index.html`文件
2. 在橙色背景的输入框中填写相应的值
3. 数据会自动计算，也可以点击"计算"按钮手动触发计算
4. 点击"重置"按钮可清空所有输入和输出值

## 文件说明

- `index.html`: 主页面文件
- `styles.css`: 样式表文件，负责页面布局和响应式设计
- `script.js`: JavaScript脚本文件，实现计算逻辑

## 在移动设备上使用

网页应用会根据设备屏幕大小自动调整布局：

- 在桌面浏览器中，左右两列并排显示
- 在移动设备上，两列会自动堆叠显示，便于滚动浏览
- 针对iPhone等小屏幕设备进行了特别优化，确保按钮和输入框大小合适

## 部署建议

如果需要在网络上共享使用，可以：

1. 将这些文件上传到任何网页托管服务
2. 或者使用简单的HTTP服务器在局域网内共享

```bash
# 使用Python创建简单的HTTP服务器（需要安装Python）
python -m http.server 8000
```

然后在浏览器中访问 http://localhost:8000 即可使用。
